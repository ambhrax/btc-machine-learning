Project Overview

The Idea & Approach

An end-to-end ML pipeline that predicts Bitcoin's next-candle price, classifies directional trends, and simulates algorithmic trading with real transaction costs.

Why This Project?

Cryptocurrency markets present a uniquely challenging prediction problem: high volatility, 24/7 trading, micro-structure noise, and fat-tailed return distributions that violate Gaussian assumptions. This project systematically benchmarks how three fundamentally different ML paradigms handle this challenge across timescales from 1-minute scalping to 30-day macro positioning.

Core Hypothesis: The predictive utility of machine learning models varies significantly across timeframes — higher timeframes should yield better directional accuracy and profitability due to reduced noise and lower transaction cost friction relative to signal magnitude.

The 3 ML Paradigms

Ridge Regression — Linear baseline with L₂ regularization. Tests if a simple linear model can capture price dynamics.

Random Forest — Ensemble bagging of 100 decision trees. Captures non-linear interactions via averaging.

LightGBM — Gradient boosted trees with histogram-based binning. Sequential error correction for complex patterns.

Stage 01

Data Acquisition

Historical OHLCV data fetched from Binance's public spot API via CCXT, with custom timeframe resampling using standard financial candlestick rules.

How It Works

The data loader connects to the Binance public spot API without requiring any private keys. It uses paginated OHLCV fetching to retrieve up to 1,200 candles per timeframe.

For timeframes not natively supported by Binance (10m, 4d, 30d), the system derives them by resampling from a higher-resolution base:

  • • 10m → resampled from 5m candles
  • • 4d → resampled from 24h (1d) candles
  • • 30d → resampled from 24h (1d) candles
Open = first  |  High = max  |  Low = min
Close = last  |  Volume = Σ

Key Formulas

RSI = 100 − 100 / (1 + RS)
RS = avg_gain(14) / avg_loss(14)
MACD = EMA(12) − EMA(26)
Signal = EMA(9) of MACD
Histogram = MACD − Signal
Bollinger Upper = SMA(20) + 2σ
Bollinger Lower = SMA(20) − 2σ
BB Width = (Upper − Lower) / Middle
Log Return: rₜ = ln(Pₜ / Pₜ₋₁)
Target: Pₜ₊₁ = close.shift(−1)

Training Methodology

Chronological Split (80/20)

Time series data must NOT be randomly shuffled. We use the first 80% of data for training and the last 20% for testing — preserving temporal order to prevent lookahead bias.

Leak-Free Scaling

StandardScaler is fitted exclusively on the training partition. The test set is transformed using train statistics only — never fit on test data, preventing information leakage.

Directional Accuracy = (1/N) × Σ 𝟙(sign(P̂ₜ₊₁ − Pₜ) == sign(Pₜ₊₁ − Pₜ))

Insights

Key Learnings & Viva Defense

Critical design decisions, empirical findings, and common questions answered with evidence from the results.

Financial prices are autocorrelated time series. Standard random-shuffle k-fold CV would leak future price information into the training set, creating artificially inflated metrics that don't reflect real trading performance.

We strictly use chronological forward splits: train on the first 80% of data, test on the last 20%. This ensures no future data ever contaminates the model during training — exactly as in real-world deployment.

Because price Pₜ₊₁ is strongly correlated with Pₜ, a naive model predicting Pₜ₊₁ ≈ Pₜ achieves low RMSE and high R² but zero trading utility.

Directional Accuracy (predicting whether the candle closes higher or lower than the current price) directly determines trade profitability. A model with higher RMSE but better directional accuracy will generate more profitable trading signals than a model that simply "copies" the current price.

Two compounding factors:

1. Signal-to-Noise Ratio: High-frequency candles (1m, 3m) contain substantial micro-structure noise — random fluctuations that don't represent tradeable trends. Longer timeframes (4h, 24h, 4d) filter out this noise, revealing clearer price trends.

2. Fee Drag: With 0.1% fee per trade (0.2% round-trip), a 1-minute strategy needs each trade to capture >0.3% move just to break even. At 4-day horizons, trades typically capture 2-10% moves, making fees insignificant relative to signal magnitude.

The close price has 80.79% importance in Random Forest because the target variable (next candle's close) is highly autocorrelated with the current close. The model learns that "tomorrow's price ≈ today's price + small change".

LightGBM distributes importance more evenly across features (17.35% for close) because gradient boosting's sequential error correction naturally focuses on residual patterns — the small deviations that technical indicators like RSI, MACD, and volatility measures can explain.

The best overall performer is LightGBM on the 4-day timeframe:

  • • Final Balance: $12,145.07 (+$2,145.07)
  • • Total Return: +21.45%
  • • Win Rate: 100% (2/2 trades)
  • • Sharpe Ratio: 2.11
  • • vs Buy & Hold: +10.35% outperformance

Ridge Regression achieved $11,011.30 (+10.11%) on 24h and $11,087.89 (+10.88%) on 4d — both outperforming Buy & Hold. This occurs because:

1. At longer timeframes, price trends are more linear and persistent, favoring linear models.

2. L₂ regularization prevents overfitting to noise, making Ridge more robust for out-of-sample prediction on long horizons where the underlying signal is smoother.
